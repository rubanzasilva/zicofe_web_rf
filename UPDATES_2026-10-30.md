# ZICOFE Website — Recent Changes

Prepared: 30 October 2026 (Africa/Kampala).

This summary covers the work recorded from 21–30 October 2026, focusing on the recent updates from 27–30 October. It is based on Git history, the current working tree, and the checks performed during this session. It includes committed website updates and the order-form changes that remain uncommitted at the time of writing. Deployment has not been verified.

## Shop Now order form

### Validation and submission behavior

- Grouped the coffee-type radio buttons so selecting one type satisfies the required choice. Also grouped the quantity-unit radio buttons.
- Moved the coffee-grade options and order validation into `src/lib/order.ts`, shared by the browser and API route.
- Added validation for required text, field lengths, email, phone, quantity, unit, coffee type, and the grade belonging to the selected type.
- Added a guard against submitting again while a request is pending.
- Required an explicit successful response before showing confirmation and resetting the form.
- Preserved customer entries when submission fails and handled non-JSON responses without crashing the form.
- Added accessible success/error announcements and direct sales-email and WhatsApp links alongside error messages.

### FormSubmit integration

- Replaced Resend with FormSubmit while keeping the existing `/api/send-order-email` route.
- Configured `silva@zicofe.com` as the default order inbox, with an override through `FORMSUBMIT_EMAIL`.
- Included customer contacts, company, coffee type and grade, entered quantity, kilogram/bag totals, delivery address, and notes in the notification.
- Set the customer's email as the reply address and selected FormSubmit's table email template.
- Included the originating shop URL and `Referer`/`Origin` headers.
- Added a 15-second service timeout and clearer handling for rejected requests, unavailable service, rate limits, malformed responses, and activation messages.
- Removed the unused `resend` and `@react-email/render` dependencies and updated the package lockfile.
- Updated `.env.example` and the README with the new configuration and activation steps. Resend API keys and verified sending-domain setup are no longer used by the form.

Main files: `src/app/shop/page.tsx`, `src/app/api/send-order-email/route.ts`, `src/lib/order.ts`, `package.json`, `package-lock.json`, `.env.example`, and `README.md`.
