## Technical Architecture Updates

### API Routes Structure
```
src/app/api/
└── send-order-email/
    └── route.ts         # POST endpoint for order emails
```

### Pages Structure
```
src/app/
├── page.tsx            # Home page (existing)
└── shop/
    └── page.tsx        # New shop/order page
```

### Email Flow Architecture
1. **User Input:** Customer fills order form on `/shop`
2. **Client-Side Validation:** React form validation + HTML5 constraints
3. **API Call:** POST to `/api/send-order-email` with order data
4. **Server Processing:**
   - Validate required fields
   - Calculate KG/bags totals
   - Generate HTML email template
   - Send via Resend API
5. **Response Handling:**
   - Success: Show confirmation, reset form
   - Error: Display error message, preserve form data
6. **Email Delivery:** Order details sent to configured recipient
