## Configuration Updates

### Next.js Image Configuration

**Issue:**
- External images from Unsplash were blocked
- Error: "hostname 'images.unsplash.com' is not configured"
- Prevented carousel images from loading

**Solution:**
- Updated `/next.config.js` to allow external images
- Added `images.unsplash.com` to domains array

**Configuration:**
```javascript
const nextConfig = {
  images: {
    domains: ['images.unsplash.com'],
  },
}
```

**Result:** Carousel images now load properly from Unsplash
